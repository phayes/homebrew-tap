# homebrew-tap

Patrick Hayes' Homebrew tap for command-line tools.

## Usage

```
brew tap phayes/tap
brew install <formula>
```

## Formulas

Formulas in `Formula/` are published and kept up to date automatically by
[cargo-dist](https://opensource.axo.dev/cargo-dist/) as part of each source
project's release workflow. Don't edit them by hand — a PR against the
formula here will be overwritten on the next release of the source project.
